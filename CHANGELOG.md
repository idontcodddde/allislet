# Changelog

## Allislet SDK v1.0.0

### Added
- initial stable SDK release for shadow-isolated browser app development
- closed Shadow DOM host bootstrap and mount lifecycle
- Preact provider and service context for runtime singletons
- config-driven feature activation through allislet.config.ts
- dynamic JSON loading via useData and data path resolution
- network interception for fetch, XHR, and socket lifecycle control
- browser automation tooling for DOM observation, form fill, and macro recording
- floating overlay system with docking, windows, toasts, and command palette support
- built-in realtime chat, direct messaging, and admin execution surfaces
- Bun-based development and build workflow

### Changed
- standardized public versioning to v1.0.0
- improved documentation structure and project operating model
- clarified bootstrapping and config-first runtime architecture

### Fixed
- improved runtime configuration clarity for host-safe mounting and lifecycle behavior
- cleaned up project metadata and release documentation flow
